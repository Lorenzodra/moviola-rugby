# Moviola CUS Torino Rugby

App per rivedere le partite sul **video originale** senza tagliarlo: partita intera, condensata (solo palla in gioco),
mischie, touche, maul, tutte le fasi statiche o una selezione di tag. Tag modificabili, esportabili e importabili.

Pagina pubblica: https://lorenzodra.github.io/moviola-rugby/

I video **non** sono nel repository: ognuno apre il proprio file dal computer (pulsante «Apri video»).
Le pagine delle partite sono generate da `crea_moviola.py` del progetto di analisi.
